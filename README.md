# רעש שמציל — Sound of Survival

**כדי לראות את הדרך, תצטרך להשמיע קול. אבל כל קול עלול להיות האחרון שלך.**

## על המשחק

**רעש שמציל** הוא משחק דו־ממדי של הישרדות, התגנבות וחשיבה, המתרחש במתקן מחקר חשוך. השחקן צריך למצוא חפצים, לפתוח דלתות ולברוח מהמתקן בלי להיתפס.

היכולת המרכזית במשחק היא **הפקת גלי קול שחושפים את הסביבה לזמן קצר**. אבל יש מחיר: אויבים שומעים את הקול ומתקדמים אל המקום שממנו הופק. בהמשך ניתן להשתמש במכשירי רעש מרוחקים כדי להסיח את דעתם וליצור דרך מילוט.

## פרטי המשחק

- **סוג:** הישרדות, התגנבות ופתרון חידות
- **פלטפורמה:** מחשב אישי (Windows)
- **מספר שחקנים:** שחקן יחיד
- **תצוגה:** דו־ממד, מבט מלמעלה
- **שליטה מתוכננת:** מקלדת

## איך משחקים?

1. נעים במבוך החשוך ומפיקים גלי קול כדי לגלות מעברים, חפצים ואויבים.
2. מחליטים מתי להמשיך בחושך ומתי להפיק קול נוסף, שעלול למשוך אויבים.
3. אוספים את חפצי המשימה, משתמשים בהסחות דעת ומגיעים לדלת היציאה.
